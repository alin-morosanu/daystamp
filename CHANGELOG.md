## [Unreleased]

### Added
- Named date presets with a live preview, day offsets and an optional link to the daily note.
- Ribbon icon that inserts the default preset; its tooltip shows the preset.
- Commands for the default preset, the calendar and every preset; hotkeys survive renames.
- Inline trigger `@@` with offsets (`@@+3`, `@@-1`) and filtering by name.
- Keyboard-accessible calendar with a preset picker and live preview.
- Editor context menu entries "Insert date" and "Insert date from calendar…".
- Format chips, reset presets to defaults, and undo for deletes and resets.
- Optional space after insert.
