# Use Daystamp on mobile

Everything works on iOS and Android: the ribbon icon, commands, the `@@` trigger and the calendar.

## Add a toolbar button

The quickest way to insert a date on mobile is a button in the editing toolbar:

1. Open **Settings → Mobile → Manage toolbar options**.
2. Find **Daystamp: Insert default date** and add it.

Tap the button to insert your default preset. You can add **Daystamp: Insert date from calendar** or any preset command the same way.

## Tips

- In the calendar, tap a day to select it and tap **Insert**, or double-tap the day.
- In settings, tap **Add preset** under the **Presets** list to add one.
- If your on-screen keyboard makes `@@` awkward, [change the trigger](change-the-trigger.md).
