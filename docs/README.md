# Daystamp documentation

Daystamp inserts dates and times into your Obsidian notes, in formats you choose, from a calendar, a ribbon icon, commands or an inline trigger.

Pick the section that matches what you want to do.

## For users

**New to Daystamp?** Start with [Getting started](user/getting-started.md). It takes about five minutes and walks you through inserting a date in each of the four ways.
